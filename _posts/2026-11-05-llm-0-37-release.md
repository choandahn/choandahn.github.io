내 LLM CLI 도구 겸 Python 라이브러리의 이번 릴리스에는 두 달 가까이 쌓인 기능과 수정이 들어갔다. 분량이 꽤 된다.

`gpt-6.1-sol`과 `gpt-6.1-terra` 모델을 추가했고, OpenAI 호환 엔드포인트를 쓰는 추가 모델 설정을 쉽게 만들려고 [`llm openai endpoint add`](https://llm.datasette.io/en/stable/other-models.html#configure-an-openai-compatible-model) 명령도 새로 넣었다.

기본 모델(직접 기본값을 설정하지 않은 경우)을 `gpt-6-luna`로 바꿨다. 이전 기본값인 `gpt-5.6-luna`의 절반 가격이다.

임베딩 지원도 바뀌었다. 이제 서로 다른 바이너리 콘텐츠가 서로 다른 content-type을 가질 수 있다는 걸 받아들인다. 텍스트, 오디오, 이미지, 비디오를 임베딩할 수 있는 [Gemini Embedding 2](https://deepmind.google/models/gemini/embedding/) 같은 모델에는 이렇게 동작해야 한다.

오픈소스 메인테이너들은 AI 보조 PR의 홍수를 두고 불폐를 많이 한다. llm은 내 프로젝트 중 이 영향을 가장 많이 받는 프로젝트인데, 솔직히 말하면 문제라고 느끼지 않는다. 주된 이유는 트리아지를 Opus 5.5나 GPT-6 Astra에게 맡겨 가장 유용한 수정을 골라내기 때문이다!

이번 릴리스에는 12명 기여자의 수정이 들어갔다. 거의 전부 AI 보조로 작성됐고, 검토 부담은 내가 예상했던 것보다 훨씬 적었다. 나는 이런 PR들을 예시가 붙은 버그 리포트로 취급한다. 어떤 것은 그대로 머지하고, 어떤 것은 내 방식대로 직접 고쳐 넣는다.
